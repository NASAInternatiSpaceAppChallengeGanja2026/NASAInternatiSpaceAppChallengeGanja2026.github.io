## 🚀 Overview

This repository hosts the public, zero-backend, client-side interactive showcase and simulation platform for the **Mars Food Intelligence** project.

It runs entirely in-browser on GitHub Pages with:
1. **Executive Sol-450 Mission Dashboard** with live telemetry and bio-regenerative agriculture status.
2. **Space Food Data Laboratory** with 100% schema audit and empirical NASA JSC food lab validation benchmarks ($R^2 \ge 0.99$).
3. **Arrhenius Degradation Kinetics Engine** with reactive SVG vector degradation curves and Drop-Dead Sol computation.
4. **SciPy-Style Constrained Diet Optimizer** balancing calories, proteins, vitamins, mass, and water under NASA-STD-3001 limits.
5. **Mars Mission Simulator** with Sol-by-Sol dynamic failure injection (refrigeration failure, crop blight) and event logging.
6. **Mathematical & Biophysical Architecture** equations and proofs.

## 🛠️ Local Development & Preview

You can open `index.html` directly in any web browser, or run a local static server:

```bash
# Using Python
python3 -m http.server 8080

# Or npx serve
npx serve .
```

Open [http://localhost:8080](http://localhost:8080).
